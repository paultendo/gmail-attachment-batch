Set up Gmail Attachment Batch

Download attachments from a reviewed Gmail search, organised into folders. Runs in your signed-in browser with Tampermonkey.

  1. Install Tampermonkey in Chrome.
    Open Tampermonkey in the Chrome Web Store. If it is already installed, move to step 2.
  2. Add Attachment Batch.

    Install the script directly with Tampermonkey. If that opens code, use the copy button below.

    Open the Tampermonkey extension → Dashboard → Create a new script. Copy the script here, replace the entire template in the editor, then save with Ctrl+S (Windows) or ⌘S (Mac).

    Show script / copy manually
  3. Open Gmail and check setup.

    Refresh Gmail. Next to Refresh and More, find Attachment Batch → Help. Follow its setup check to enable folder downloads and save a small test file. Then try a search with one or two known attachments.

The Attachment Batch buttons have not appeared

Check that this script is enabled in the Tampermonkey dashboard. Open Chrome → Extensions → Manage Extensions → Tampermonkey → Details, and enable Allow User Scripts if shown. Refresh Gmail afterwards. This prototype is for English Gmail in desktop Chrome. Tampermonkey’s official instructions.

Folder download settings, step by step
  1. Open Tampermonkey → Dashboard → Settings.
  2. Set Config mode to Advanced.
  3. Under Downloads, set Download Mode to Browser API, then Save. Allow Chrome’s download permission if requested.
  4. Refresh Gmail, then choose Attachment Batch → Help → Check download setup. You can return Config mode to Novice afterwards.

Some file types need adding to Whitelisted File Extensions. Permit the attachment types you need, .txt for the setup check and .csv for reports. Chrome’s “Ask where to save each file” setting controls repeated save prompts.

Download your first batch

Search Gmail → Download attachments → Capture results → Review list. Untick anything you do not want, choose your folder, then download and save the report. Leave the Gmail tab open while it works.

Each selected result can be a whole conversation, including replies. Opening unread messages may mark them as read. Start with a small search and check the saved files.
